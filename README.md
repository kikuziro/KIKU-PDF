# PDF 필기장 앱 설치 안내

PDF에 형광펜, 밑줄, 펜, 메모로 필기하고 저장하면 원본 파일에 바로 반영되는 앱이에요.
이 폴더를 웹 주소에 한 번 올려 두면 다음과 같이 쓸 수 있어요.

- Chrome이나 Edge에서 **앱으로 설치**해서 바탕화면 아이콘과 독립된 창으로 써요.
- 한 번 연 뒤에는 **인터넷 없이도** 열려요.
- PDF 파일을 **더블클릭하면 바로 이 앱으로** 열리게 할 수 있어요.

PDF 파일은 어디에도 올라가지 않아요. 열기, 필기, 저장이 모두 내 컴퓨터 안에서만 이루어져요.

---

## 1. 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면과 기능 전체 |
| `manifest.webmanifest` | 앱 이름, 아이콘, 'PDF 열기 프로그램' 등록 정보 |
| `sw.js` | 앱 파일을 컴퓨터에 저장해서 오프라인으로 열리게 함 |
| `icons/` | 앱 아이콘 |
| `vendor/` | PDF를 그리고 저장하는 엔진(pdf.js, pdf-lib)과 한글 글자표 |

파일과 폴더 구조를 그대로 둬야 해요. `vendor` 폴더가 `index.html` 옆에 있어야 동작해요.

## 2. 웹 주소에 올리기 (GitHub Pages, 무료)

1. [github.com](https://github.com)에 가입하고 로그인해요.
2. 오른쪽 위 **+** → **New repository**를 눌러요.
   - Repository name: 예) `pdf-pilgi`
   - **Public**을 선택해요. 무료 계정은 공개 저장소에서만 Pages를 쓸 수 있어요. 공개되는 것은 앱 코드뿐이고, 내 PDF는 올라가지 않아요.
   - **Create repository**를 눌러요.
3. 새 저장소 화면에서 **uploading an existing file** 링크를 눌러요.
4. 이 폴더 **안의 내용 전부**(index.html, manifest.webmanifest, sw.js, README.md, icons 폴더, vendor 폴더)를 끌어다 놓아요.
   폴더 자체가 아니라 그 안의 항목들을 올려야 해요.
5. 아래쪽 **Commit changes**를 눌러요.
6. 저장소의 **Settings** → 왼쪽 **Pages**로 가요.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
7. 1~2분 뒤 같은 화면 위쪽에 주소가 나와요.
   예) `https://내아이디.github.io/pdf-pilgi/`

## 3. 앱으로 설치하기

1. Chrome이나 Edge로 위 주소를 열어요.
2. 첫 화면의 **앱으로 설치** 버튼을 눌러요.
   버튼이 안 보이면 주소창 오른쪽의 설치 아이콘(모니터에 화살표 모양)을 눌러요.
3. 바탕화면과 시작 메뉴에 **PDF 필기장**이 생겨요.

## 4. PDF를 더블클릭해서 바로 열기

**Windows**
1. 아무 PDF 파일이나 오른쪽 클릭 → **연결 프로그램** → **다른 앱 선택**을 눌러요.
2. 목록에서 **PDF 필기장**을 고르고 **항상**을 눌러요.
3. 처음 열 때 "PDF 필기장에서 이 파일을 열도록 허용할까요?"라고 물으면 허용해요.

**Mac**
1. PDF 파일을 선택하고 `⌘ + I`(정보 가져오기)를 눌러요.
2. **다음으로 열기**에서 **PDF 필기장**을 고르고 **모두 변경**을 눌러요.

이제 PDF를 더블클릭하면 앱이 열리고, 저장하면 그 파일에 바로 덮어써져요.
처음 저장할 때 "이 파일을 수정하도록 허용할까요?"라고 한 번 물어봐요.

## 5. 앱을 고치거나 업데이트할 때

1. 파일을 고친 뒤 `sw.js` 맨 위의 `VERSION` 숫자를 하나 올려요.
   예) `'pdf-pilgi-v1'` → `'pdf-pilgi-v2'`
2. 고친 파일들을 GitHub 저장소에 다시 올려요. 같은 이름이면 덮어써져요.
3. 설치한 앱을 두 번 껐다 켜면 새 버전으로 바뀌어요.

`VERSION`을 올리지 않으면 이미 설치한 컴퓨터에는 예전 버전이 계속 보여요.

## 6. 내 컴퓨터에서만 시험해 볼 때

웹에 올리기 전에 확인하고 싶다면, 이 폴더에서 터미널을 열고 다음을 실행해요.

```
python -m http.server 8000
```

그다음 Chrome에서 `http://localhost:8000`을 열면 설치와 오프라인 기능까지 똑같이 시험할 수 있어요.

`index.html`을 더블클릭해서 바로 열어도 필기와 저장은 돼요. 다만 이 방식에서는 앱 설치와 오프라인 사용이 안 되고, 일부 한글 PDF에서 글자 선택이 안 될 수 있어요.
